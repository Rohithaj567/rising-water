PROJECT OVERVIEW

About Rising Water

Rising Water is an academic machine-learning prototype that estimates a flood-risk category from 20 environmental and infrastructure indicators. The supplied dataset contains a continuous FloodProbability target; this project derives a binary label using a documented 0.50 threshold.

Workflow

  1. Load and inspect the dataset.
  2. Validate columns and missing values.
  3. Derive the binary target from FloodProbability.
  4. Split data into training and testing sets.
  5. Train and compare Decision Tree, Random Forest, KNN and XGBoost classifiers.
  6. Evaluate accuracy, precision, recall, F1-score and ROC-AUC.
  7. Save the selected model and use it in the Flask application.

Model evaluation

The measured metrics for this ZIP's 50,000-row dataset are stored in reports/model_metrics.json. The model is evaluated on a held-out test split. Results are dataset-specific and do not establish real-world forecasting accuracy.
